🌐 HTML & CSS

HTML xây dựng cấu trúc nội dung website, CSS giúp định dạng màu sắc, bố cục và giao diện.

HTML cơ bản

DOCTYPE, html, head, body, heading, paragraph, image, link và table.

CSS cơ bản

Selector, màu sắc, font chữ, margin, padding và border.

Responsive

Thiết kế website tương thích với máy tính, máy tính bảng và điện thoại.

☕ Lập trình Java

Java là ngôn ngữ lập trình hướng đối tượng, được sử dụng rộng rãi trong phát triển phần mềm.

Biến và kiểu dữ liệu

int, double, float, char, boolean và String.

Câu lệnh điều kiện

if, else, else if và switch.

Vòng lặp

for, while và do while.
